## Cutting-Edge Features Incorporated

### 1. Adaptive Thinking (from Opus 4.6)
- **API:** `thinking: {type: "adaptive"}`
- **What:** Model autonomously evaluates query complexity and invokes deeper reasoning when needed. No manual `budget_tokens` setting required.
- **Why it matters:** Enables *interleaved thinking* between tool calls — the model reasons about what it found after each `file_read` or `bash` result instead of just mechanically proceeding. This is the single biggest quality differentiator.
- **Implementation:** `src/llm.py` → `_build_thinking_config()`
- **Display:** Using `display: "omitted"` for faster streaming (skip thinking tokens over the wire)

### 2. Effort Levels (from Opus 4.6)
- **API:** `output_config: {effort: "high"}`
- **Levels:** `low` → `medium` → `high` → `xhigh` (new in 4.7) → `max`
- **What:** Controls the tradeoff between intelligence/cost/latency. Maps to Claude Code's `think` / `think hard` / `ultrathink` experience.
- **Implementation:** `src/config.py` → `effort_level` field, `CLAW_EFFORT` env var, `/effort` REPL command

### 3. Thinking Block Preservation (from Extended Thinking API)
- **API:** Thinking blocks with `signature` field in assistant messages
- **What:** When Claude returns thinking blocks before tool_use blocks, these MUST be passed back unchanged in the next request. The encrypted `signature` lets the API reconstruct the full reasoning chain.
- **Why it matters:** Without this, the model loses its chain of thought after every tool call. It would reason about a bug, call `file_read`, then forget what it was looking for.
- **Implementation:** `src/llm.py` → extracts thinking blocks; `src/agent.py` → passes them through `_append_assistant_with_tool_calls_raw()`

### 4. Opus 4.7 Model Default (released 2026-04-16)
- **API:** `model: "claude-opus-4-7"`
- **Key improvements over Sonnet 4:**
  - 70% CursorBench (vs ~55% Sonnet 4)
  - More literal prompt interpretation
  - `xhigh` effort level (between high and max)
  - Updated tokenizer (1.0x-1.35x more tokens)
  - Higher-resolution vision (3.75 megapixels)
- **Implementation:** `src/config.py` → updated `PROVIDER_PRESETS` defaults

### 5. Skill Execution Parity (from Claude Code behavior)
- **What:** Claude Code pre-reads SKILL.md content and injects it into the prompt with strong execution directives. Claw was just giving the model a file path.
- **Implementation:**
  - `src/skill_registry.py` → `_read_skill_content()` pre-reads up to 40k chars
  - `build_skill_invocation_prompt()` → `EXECUTE SKILL:` header with 10 critical rules
  - `src/system_prompt.py` → persistent "Skill execution" section
